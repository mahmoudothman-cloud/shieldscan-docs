### 3.1 Q1 (γ) `parseReport` Platform-Gated Invocation Refactor

**Implementation surface:** `parser.go` line 195-209 refactor.

Current shape (PRE-V10):

```go
parseReport(body []byte, platform string) (*Report, error) {
    ... unmarshal r ...
    parseCodeAnalysis(r.CodeAnalysis, platform)
    adaptManifestFindings(r.ManifestAnalysis, platform)
    adaptPermissions(r.Permissions, platform)
    adaptNetworkSecurity(r.NetworkSecurity, platform)
    adaptBinaryAnalysis(r.BinaryAnalysis, platform)
    adaptSecrets(r.Secrets, platform)
    adaptCertificateFindings(r.CertAnalysis, platform)
    adaptTrackers(r.Trackers, platform)
}
```

Post-V10 shape:

```go
parseReport(body []byte, platform string) (*Report, error) {
    ... unmarshal r ...
    parseCodeAnalysis(r.CodeAnalysis, platform)
    adaptPermissions(r.Permissions, platform)   // platform-agnostic
    adaptSecrets(r.Secrets, platform)           // platform-agnostic
    adaptTrackers(r.Trackers, platform)         // platform-agnostic
    if platform == "android" {
        adaptManifestFindings(r.ManifestAnalysis, platform)
        adaptNetworkSecurity(r.NetworkSecurity, platform)
        adaptCertificateFindings(r.CertAnalysis, platform)
        var binaries []AndroidBinaryEntry
        json.Unmarshal(r.BinaryAnalysis, &binaries)
        adaptBinaryAnalysis(binaries, platform)
    }
    if platform == "ios" {
        adaptInfoPlist(r.InfoPlist, platform)
        adaptATSFindings(r.ATSAnalysis, platform)
        adaptDylibAnalysis(r.DylibAnalysis, platform)
        var iosBinary IOSBinarySummary
        json.Unmarshal(r.BinaryAnalysis, &iosBinary)
        adaptIOSBinary(iosBinary, platform)
        adaptBundleURLTypes(r.BundleURLTypes, platform)
    }
}
```

Plan-level micro-decision: identify platform-agnostic adaptors empirically (V3 found `permissions` + `secrets` + `code_analysis` + `trackers` shared) and route those before platform branching for minimal LoC delta. ~40-60 LoC `parser.go` refactor.

### 3.2 Q3 (a) `binary_analysis` Shape Collision Resolution

**Mechanism:** `json.RawMessage` at struct field; platform-conditional Unmarshal per Q1 refactor (already shown in §3.1 above).

Struct field change at `parser.go`:

```go
type Report struct {
    ...
    BinaryAnalysis json.RawMessage `json:"binary_analysis"`
    ...
}
```

Existing Android adaptor `adaptBinaryAnalysis(...)` signature shifts: input parameter `[]AndroidBinaryEntry` (post-unmarshal) instead of `interface{}` (current generic). Bounded refactor at `sections.go` `adaptBinaryAnalysis` (probably ~2-5 LoC signature + body).

### 3.3 Q2 (a) 5 iOS Adaptor Implementation

Per design doc `0347a79` §4 schema grounding. Per-adaptor LoC estimates + implementation pattern:

**`adaptInfoPlist`:** plist XML parse via `github.com/howett/plist` (verify availability at execution; fallback Go stdlib `encoding/xml`). Extract `NSAppTransportSecurity` + `CFBundleURLTypes` + `NSAllowsArbitraryLoads` + `ITSAppUsesNonExemptEncryption` + `UIFileSharingEnabled` + `LSRequiresIPhoneOS` + `UIBackgroundModes` + etc. per OWASP MASVS-PLATFORM-3 + MASVS-NETWORK-1 checks. ~80-120 LoC.

Plan-level Y-decision **Y-PLIST-PARSE**: (a) Go stdlib `encoding/xml` direct OR (b) third-party `github.com/howett/plist` library. Resolve at Stage 3 Commit 2 execution; default (b) per plist-format-spec compliance.

**`adaptATSFindings`:** structured-JSON adaptor; iterate `ats_findings` list; `mapMobSFSeverity` reusable (severity lowercase canonical match). `FindingType="ats_violation"`. ~40-60 LoC.

**`adaptDylibAnalysis`:** mirror existing `adaptBinaryAnalysis` Android pattern; reuse `binarySubChecks` constant; iterate dylib list × 8 sub-checks. `FindingType="dylib_protection_missing"`; `Metadata.dylib_name` + `Metadata.sub_check` populated. ~50-70 LoC.

**`adaptIOSBinary`:** iterate `findings` dict; emit per title-key. `FindingType="ios_binary_finding"`; Severity from finding-level field; CVSS + CWE + OWASP-MASVS typed-field reuse per ADR-024 + ADR-027 Metadata. ~60-80 LoC.

**`adaptBundleURLTypes`:** iterate `bundle_url_types` list; emit per `CFBundleURLScheme`. `FindingType="ios_url_scheme"`; Severity per scheme-risk-rubric (custom = high; well-known = info); `Metadata.url_scheme` populated. ~30-50 LoC.

**Total iOS adaptor LoC:** ~260-380 LoC at `sections.go` addition.
